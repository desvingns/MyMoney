## Файлы

- `dashboard-neon-ring-mockup.png` — скриншот макета. **Положи PNG сюда вручную** (или будет снят рендером HTML на этапе сборки 06).

## Замечания заказчика (locked)
1. Свечение неонового кольца **не обрезается** сверху/снизу (сейчас в текущем донате glow срезается).
2. «Остаток» в центре — **динамически ужимается**, чтобы не касаться внутреннего края кольца.
3. Кнопки −/+ — **на 15% крупнее** (90dp → ~104dp).
4. Плитки категорий **скроллятся**, если не влезают.
5. Всё остальное — **один в один** с макетом.

## Решённая семантика (grill)
- Кольцо = единая градиентная дуга (мятный→циан), **без сегментов**; заполнение = **расход ÷ доход** за период (clamp 0..1; доход 0 → пустой трек).
- Центр = **net за период** (доход − расход), округление **до целого**, метка «Остаток»; отдельной панели баланса нет.
- Неон-палитра заменяет палитру **всего приложения**; layout-редизайн — только дашборд.
- Плитки = **только расходы**, по убыванию, полоска = доля от расхода, тап → операции категории, **без** свёртки «<2% Другое».

## Структура экрана (сверху вниз)
1. Топ-бар: ☰ · ↔(перевод) · ‹ Месяц › · 🔍 · ⋮ — белые иконки на тёмном.
2. Неоновое кольцо + центр: крупный «Остаток» + пилюля `↑ доход / ↓ расход`.
3. Скроллируемый список плиток категорий: чип-иконка + название + сумма + цветная полоска-прогресс.
4. Низ: две круглые кнопки — красная «−» (расход), зелёная «+» (доход).
