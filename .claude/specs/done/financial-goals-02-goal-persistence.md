## Gap / context
There is no goal table or repository. The goals list (SPEC 04) and the create/edit form (SPEC 05/06) need
to persist and observe goals. Adding the first new entity since v1 forces the project's first real Room
migration — done properly (non-destructive + migration test) so existing accounts/transactions survive the upgrade.
