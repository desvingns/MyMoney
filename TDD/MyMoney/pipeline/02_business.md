## Detailed per-screen description

### S01 — Main dashboard, period: Day (file: `01.jpg`)

- **Purpose (RU):** Главный экран приложения. Показывает за выбранный период (сегодня = "Воскресенье, 17 мая") баланс, доли расходов и доходов в виде кольцевой диаграммы, и все категории по периметру с процентным вкладом.
- **State:** `normal` — баланс отрицательный (−10 005,00 ₽).
- **Visible blocks:**
  - **header** — иконка-гамбургер слева (период), логотип «Monefy», подпись «Динары» (название активного счёта), иконка поиска, иконка обмена (↔ переключение видов / отчёт), троеточие (overflow menu)
  - **period_strip** — горизонтальная лента дат под хедером: «16 мая | Воскресенье, 17 мая | …» (свайп влево/вправо листает периоды)
  - **donut_chart** — пончиковая диаграмма; верхняя половина (розовая) = расходы 44 %, нижняя (зелёная) = доходы 56 %
  - **chart_center_labels** — две суммы внутри пончика: `0,00 ₽` (зелёным, доходы) и `10 005,00 ₽` (розовым, расходы)
  - **category_grid_around_chart** — 12 цветных иконок-категорий вокруг диаграммы; у двух показан процент (44 %, 56 %)
  - **balance_card** — посередине внизу: «Баланс −10 005,00 ₽» на розовом (отрицательная окраска)
  - **side_handles** — две полоски-«ручки» (≡) по бокам от balance card, открывают левый и правый drawer
  - **fab_pair** — два больших круглых FAB-а в самом низу: красный «−» (минус-расход) слева, зелёный «+» (плюс-доход) справа
- **CTA:** Гамбургер (открыть period drawer), Поиск, ↔ (переключатель режима/отчёт?), Меню (⋮), «−» (новый расход), «+» (новый доход), Balance card (тап → запись/отчёт?), ≡-ручки слева и справа (drawers)
- **Inputs:** нет (read-only)
- **Outputs:** Баланс, две агрегатные суммы в центре, проценты у каждой категории, дата выбранного периода
- **Text extracted (verbatim):** «Monefy | Динары | 16 мая | Воскресенье, 17 мая | 44% | 56% | 0,00 ₽ | 10 005,00 ₽ | Баланс −10 005,00 ₽»
- **Permissions implied:** `INTERNET` (для синхронизации/обновления курсов, если есть)
- **SDKs implied:** none directly visible
- **Gamification hooks:** анимированный «налив» сегментов диаграммы при появлении баланса; haptic-тик при свайпе периода; конфетти/звук на положительном балансе vs «тревожный» цвет на отрицательном — уже частично реализовано через смену цвета карточки
- **Confidence:** 0.95

## Business rules

| ID    | Rule (RU)                                                                                                                                | Screens         |
|-------|------------------------------------------------------------------------------------------------------------------------------------------|-----------------|
| BR-1  | Главный экран = один экран с тремя видами: пончиковая диаграмма + сетка категорий + карточка баланса; всё остальное доступно через свайп/drawer/FAB | S01, S05        |
| BR-2  | Цвет карточки «Баланс …» сигнализирует знак: розовый = отрицательный, зелёный = положительный                                            | S01, S05        |
| BR-3  | В центре пончика всегда две цифры: верхняя зелёная = сумма доходов за период, нижняя розовая = сумма расходов                              | S01, S05        |
| BR-4  | Пончиковая диаграмма имеет два главных сегмента (зелёный = доходы, розовый = расходы); подсегменты внутри расходов окрашены цветом конкретной категории | S01, S05    |
| BR-5  | Категории расположены по периметру; подпись «X %» под иконкой = доля этой категории в общих расходах за выбранный период                  | S01, S05        |
| BR-6  | Период выбирается в левом drawer: День / Неделя / Месяц / Год / Все / Интервал / Произвольная дата                                       | S02             |
| BR-7  | Активный счёт (с собственной валютой) — селектор в верху левого drawer; имя счёта дублируется в шапке дашборда                            | S01, S02, S05   |
| BR-8  | Тап «−» (красный FAB) открывает форму «Новый расход» с пустой суммой и текущей датой                                                     | S01 → S06       |

## Inferred features (для TDD, audience=gaming)

1. **Multi-account / multi-currency wallets** — пользователь может иметь несколько счетов («Динары», «Наличные», …), у каждого собственная валюта (S02, S03, S04 → «Валюты»).
2. **Period filtering** — день / неделя / месяц / год / произвольный интервал (S02). Свайп по горизонтали листает соседние периоды (S01 period strip).
3. **Donut chart with category proportions** — главный визуальный элемент. Два больших сегмента (доходы / расходы) + цветные подсегменты по категориям.
4. **Calculator-style amount entry** — числовой ввод с операциями (+ − × ÷) и десятичной точкой; результат «=» сразу применяется (S06, S07).
5. **Transactions: expense / income / transfer** — три типа операций; у первых двух есть категория, у перевода — пара счетов (S03, S06, S07).
6. **Customisable categories** — пользователь может добавить новую категорию из picker’а (S09 «(+) ДОБАВИТЬ»); набор по умолчанию — 15 категорий (Гигиена, Еда, Жильё, Здоровье, Кафе, Машина, Одежда, Питомцы, Подарки, Развлечения, Связь, Спорт, Счета, Такси, Транспорт).
7. **Free-text note per transaction** — поле «Заметка» с иконкой пера (S03, S06, S07).
8. **Date selection per transaction** — chip с текущей датой; тап → date picker (S03, S06, S07).
9. **Search records** — текстовый и голосовой поиск по транзакциям (S08).
10. **Balance card** — сводный показатель за выбранный период; цвет = знак.
11. **Side drawers (left/right)** — навигация: слева периоды + счёт, справа справочники + настройки (S02, S04).
12. **Toggle between expense and income within entry form** — иконка ⇄ в шапке формы (S06, S07).
13. **Reference dictionaries** — «Категории», «Счета», «Валюты», «Настройки» как отдельные подэкраны (S04). **Не показаны** в подборке — TDD должен предусмотреть их как stub.
